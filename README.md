# Báo cáo Bloxorz Solver

Đây là mã nguồn LaTeX và [bản PDF](main.pdf) của báo cáo Project 1, học phần CSC14003 – Cơ sở trí tuệ nhân tạo.

Biên dịch từ thư mục này bằng:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

`content/` chứa nội dung báo cáo, `ref/` chứa tài liệu tham khảo, `img/` chứa hình và biểu đồ, còn `data/` chứa dữ liệu thực nghiệm dùng trong báo cáo.

Phần định dạng dựa trên [HCMUS Unofficial Report Template](https://github.com/khongsomeo/hcmus-unofficial-report-template); thông tin giấy phép của mẫu có tại repository gốc.
